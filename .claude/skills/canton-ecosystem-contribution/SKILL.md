# Canton ecosystem contribution

Use this skill when the user wants to contribute beyond their own app: funded
ecosystem work or open-source Splice contributions.

## Two paths

1. **Canton Development Fund** — funded, milestone-based CC grants via PR to
   [canton-foundation/canton-dev-fund](https://github.com/canton-foundation/canton-dev-fund).
   Governed by CIP-0082 (emissions allocation) and CIP-0100 (process). External
   submitters need a Champion; max three proposals per week per org/champion.
2. **Splice open source** — coordinate on
   [canton-network/splice/issues](https://github.com/canton-network/splice/issues),
   prefer a **basket of related issues** or a focused initiative (for example
   [RFC 7523](https://datatracker.ietf.org/doc/html/rfc7523) support in the Splice
   Validator).

## Splice contribution workflow

1. Prepare a proposal (single topic or related issue batch).
2. Post in `#splice-contributions-external` for maintainer buy-in.
3. Incorporate public feedback.
4. Submit via GitHub (PRs/issues); add a Development Fund proposal if funding is
   needed.

## Guardrails

- Common-good, reusable outcomes fit the Development Fund; purely private product
  work does not.
- Do not skip maintainer alignment on non-trivial Splice changes.
